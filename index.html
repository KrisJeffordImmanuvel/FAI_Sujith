🎯 Project Objective & Engineering Scope

Simulation Mode

This web-based tool simulates a college campus water distribution network and applies the Breadth-First Search (BFS) graph traversal algorithm to solve the critical municipal challenge of pipe rupture fault isolation.

Key Engineering Objectives:

  • Rapid Water Loss Mitigation: Pinpoint damaged pipelines and close boundary valves automatically.
  • Localized Interruption: Use BFS level-order properties to close only the minimal boundary valves necessary.
  • Supply Continuity: Run source reachability BFS to assess which buildings remain supplied via alternate circulation loops.

📚 BFS Algorithmic Foundations & Mathematical Formulation

Theoretical breakdown of Graph Modeling, Breadth-First Search, and Hydraulic Boundary Isolation.

1. Graph Representation of Campus Water Distribution Network

A municipal water distribution system is mathematically formalized as an undirected weighted graph:
\( G = (V, E) \), where:

  • Vertices (\( V \)): Represent physical hydraulic components categorized into 4 distinct sets:
    • \( V_{\text{source}} = \{ \text{WT} \} \) — Primary elevated water tower.
    • \( V_{\text{junction}} = \{ \text{J1}, \text{J2}, \text{J3}, \text{J4}, \text{J5} \} \) — Distribution manifolds.
    • \( V_{\text{valve}} = \{ \text{V1}, \text{V2}, \text{V3}, \text{V4} \} \) — Boundary gate & butterfly isolation valves.
    • \( V_{\text{building}} = \{ \text{Hostel}, \text{Laboratory}, \text{Canteen}, \text{Academic}, \text{Library} \} \) — Consumer sinks.
  • Edges (\( E \)): Represent underground pipelines connecting node pairs \( (u, v) \), characterized by length \( L \) (meters), internal diameter \( D \) (mm), and maximum design flow \( Q \) (L/min).

2. Why Breadth-First Search (BFS) is Optimal for Isolation

In unweighted graph topologies where each pipeline segment constitutes a uniform search hop:

Minimal Isolation Perimeter Property:

Because BFS visits nodes in strictly non-decreasing order of distance from the source endpoints, it guarantees encountering the geometrically and topologically closest isolation valves surrounding a pipeline rupture. This guarantees that the absolute minimum number of unaffected campus buildings are cut off from water supply.

Time Complexity: \( O(V + E) \) | Space Complexity: \( O(V) \)

3. Phase 1 Algorithm: Boundary Isolation Valve Identification

When pipeline \( e = (u_{\text{fault}}, v_{\text{fault}}) \) ruptures, multi-source BFS begins simultaneously from both endpoints:

Algorithm FirstBFS(u_fault, v_fault, G): Input: Fault endpoints u_fault, v_fault, Network Graph G = (V, E) Output: Set of boundary isolation valves B Initialize Queue Q ← Empty Initialize Visited Set V_visited ← { u_fault, v_fault } Initialize Boundary Set B ← Empty For each endpoint ep in { u_fault, v_fault }: If Node_Type(ep) == 'valve': B.add(ep) Else: Q.enqueue(ep) While Q is not empty: curr ← Q.dequeue() For each neighbor nbr in Adjacent_Nodes(curr): If (curr, nbr) == (u_fault, v_fault) or (curr, nbr) == (v_fault, u_fault): Continue // Skip damaged pipe If nbr not in V_visited: V_visited.add(nbr) If Node_Type(nbr) == 'valve': B.add(nbr) // Boundary valve reached! // STOP branch expansion: Do NOT enqueue nbr Else: Q.enqueue(nbr) // Continue level expansion Return B

4. Phase 2 Algorithm: Campus Reachability & Building Impact

Simulates closing boundary valves \( B \), eliminating the fault, and tracing water propagation from the Water Tower:

Algorithm SecondBFS(Water_Tower, Closed_Valves, G): Input: Water Tower 'WT', Set of closed valves B, Graph G Output: Reachable_Buildings, Affected_Buildings Initialize Queue Q ← Empty Initialize Reachable Set R ← { WT } Q.enqueue(WT) While Q is not empty: curr ← Q.dequeue() If curr in Closed_Valves: Continue // Closed valve blocks downstream flow For each neighbor nbr in Adjacent_Nodes(curr): If (curr, nbr) is faulty pipe: Continue If nbr in Closed_Valves: R.add(nbr) // Flow reaches valve inlet, but stops Continue If nbr not in R: R.add(nbr) Q.enqueue(nbr) Operational_Buildings ← All buildings in R Affected_Buildings ← All buildings NOT in R Return Operational_Buildings, Affected_Buildings
